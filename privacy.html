Kebijakan Privasi — Aurora Harvest

Terakhir diperbarui: 17 November 2026. Pengembang: gentle-walrus-31.

Bahasa Indonesia

Aurora Harvest tidak mengumpulkan data pribadi apa pun. Game ini:

  • Tidak meminta akun, nama, email, atau informasi pribadi lainnya.
  • Tidak menampilkan iklan dan tidak memakai pelacak, analitik, atau SDK pihak ketiga.
  • Tidak mengirim data apa pun ke server. Semua permainan berjalan sepenuhnya di perangkat Anda.
  • Hanya menyimpan skor terbaik Anda di perangkat Anda sendiri (penyimpanan lokal peramban), yang dapat Anda hapus kapan saja dengan menghapus data situs.
  • Tidak mengumpulkan data anak-anak, karena memang tidak mengumpulkan data siapa pun.

Jika kebijakan ini berubah, perubahan akan dicantumkan di halaman ini. Pertanyaan dapat disampaikan melalui repositori GitHub Aurora Harvest.

English

Aurora Harvest collects no personal data. The game:

  • Does not ask for an account, name, email, or any other personal information.
  • Shows no ads and uses no trackers, analytics, or third-party SDKs.
  • Sends no data to any server. All gameplay runs entirely on your device.
  • Only stores your best score locally on your own device (browser local storage), which you can clear at any time by clearing site data.
  • Collects no data from children, because it collects no data from anyone.

If this policy changes, the change will be noted on this page. Questions can be raised via the Aurora Harvest GitHub repository.
